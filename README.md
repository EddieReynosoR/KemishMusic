## 📝 Description

**KemishMusic** is a Windows desktop application designed to provide a smooth and intuitive music playback experience. Built using **.NET Windows Forms** and integrated with **SQL Server**, it allows for persistent storage of playlists, playback history, and user preferences.

Whether you want to organize your favorite tracks or simply enjoy some background music, KemishMusic brings simplicity and functionality in one package.

---

## 💻 Built With

<p align="center">
  <img src="https://skillicons.dev/icons?i=dotnet,csharp,visualstudio,mssql" alt="Tech stack" />

- **.NET Framework** – for building the desktop application  
- **C#** – application logic and UI behavior  
- **Windows Forms** – user interface  
- **SQL Server** – for storing playlists, songs metadata, and user data  
- **ADO.NET / Entity Framework** – for database connectivity  
- **Visual Studio** – main development environment

---

## 🎧 Features

- 🎶 Local audio playback (MP3, WAV, etc.)
- 🗂️ Playlist creation, editing, and saving to database
- 🕹️ Full playback control: Play, Pause, Stop, Next, Previous
- 🔁 Repeat and Shuffle
- 🧾 Display of song metadata (title, artist, duration)
- 🛢️ Persistent storage of user settings via SQL Server
